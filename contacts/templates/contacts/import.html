Как устроен файл

Версия формата 1

Основной вариант — информация о контактах в XML. Дополнительно можно импортировать и экспортировать те же данные в JSON. Для каждого контакта доступны поля first_name, last_name, phone, email, company, city, category, birthday, notes.

XML
<?xml version="1.0" encoding="utf-8"?>
<contacts version="1">
  <contact>
    <first_name>Анна</first_name>
    <last_name>Соколова</last_name>
    <email>anna@example.com</email>
    <category>work</category>
  </contact>
</contacts>
JSON
{
  "version": 1,
  "contacts": [{
    "first_name": "Анна",
    "last_name": "Соколова",
    "email": "anna@example.com",
    "category": "work"
  }]
}

Группы: work, friends, family, other (по умолчанию). Дата рождения: ГГГГ-ММ-ДД. Все значения полей контакта — строки. Неизвестные поля, повторяющиеся ключи и XML-сущности не допускаются.
